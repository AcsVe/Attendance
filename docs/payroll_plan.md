# خطة وحدة الرواتب والخصومات (مؤجَّلة)

> الحالة: **مؤجَّلة بقرار الإدارة** (أكتوبر 2026). لا يوجد في النظام حالياً أي احتساب مالي.
> تُستأنف بعد أن تعمل بيانات الحضور الجديدة (البصمات الوسطى، نسيان الانصراف، المغادرة المبكرة، الإجازات) شهراً كاملاً وتُراجَع.

## المبدأ العام
- كل جزء **خيار مستقل يُفعَّل أو يُعطَّل**، وكلها **معطّلة افتراضياً**.
- مفتاح رئيسي للوحدة كلها؛ عند إطفائه تختفي صفحات الرواتب.
- صلاحية مستقلة «الرواتب»: لا يرى المبالغ إلا من تُمنح له (ولا مدير القسم افتراضياً).
- كل تغيير (راتب، قاعدة خصم، اعتماد شهر) في سجل التدقيق.
- لا يُعتمد خصم تلقائياً: النظام يحسب «مسودة» والإدارة تراجع وتعتمد.

## المكوّنات
1. **بيانات الرواتب**: الأساسي والعلاوات الثابتة؛ أجر اليوم = الراتب ÷ (أيام العمل الفعلية للشهر أو 30) — اختيار.
2. **خصم التأخير** (كل خيار بمفتاحه): بالدقيقة / بالشرائح (مثلاً 1–15 إنذار، 16–30 ربع يوم…) / بالتكرار (كل N مرات = يوم) / رصيد سماح شهري.
3. **خصم المغادرة المبكرة**: نفس القواعد بإعدادات منفصلة.
4. **خصم الغياب بلا عذر**: أجر يوم أو مضاعف؛ لا خصم على الإجازات والاستثناءات وطلبات التصحيح المعتمدة.
5. **نسيان الانصراف**: لا خصم / خصم ثابت بعد N مرات / يُعامل كمغادرة مبكرة.
6. **تجاوز الخروج المؤقت**: خصم الزيادة على المدة المسموحة فقط.
7. **العمل الإضافي المدفوع**: مُعامل لأيام العمل وآخر للعطل؛ خيار اشتراط موافقة مسبقة.
8. **حد أقصى للخصومات** الشهرية كنسبة من الراتب.
9. **إقفال الشهر** بعد الاعتماد؛ فتحه بصلاحية الرواتب مع سبب مسجَّل.
10. **قسيمة الراتب** للموظف في تطبيقه بتفاصيل كل خصم وسببه.
11. **إنذار قبل الخصم** («هذا تأخيرك الثالث هذا الشهر»).
12. **تصدير للمحاسبة/البنك** (Excel بصافي الراتب).

## مراحل التنفيذ المقترحة
1. قواعد الخصم **بالوقت فقط** (مثل «0.5 يوم») كعمود في «الكشف الشهري» — مراجعة شهر كامل قبل ربطها بالمال.
2. بيانات الرواتب + تحويل الأيام لمبالغ + العمل الإضافي المدفوع + الحد الأقصى + الإقفال.
3. القسيمة للموظف + الإنذارات + التصدير للبنك.

## أسئلة يجب حسمها قبل البدء
- طريقة خصم التأخير (دقيقة / شرائح / تكرار) ورصيد السماح الشهري.
- سياسة نسيان الانصراف.
- هل القواعد موحّدة أم تختلف حسب القسم.

## تنبيه قانوني
الخصم من الأجر ونسب العمل الإضافي وحدودها ينظّمها **قانون العمل الأردني**؛ لذلك كل الأرقام قابلة للضبط بلا قيم افتراضية،
ويُستحسن مراجعة المحاسب/المستشار القانوني للقواعد قبل التفعيل.
