# pyzk (vendored)

هذه الحزمة منسوخة من مشروع [pyzk](https://github.com/fananimi/pyzk) (إصدار 0.9)
مباشرة داخل المشروع بدل الاعتماد على تثبيتها عبر pip - لأن حزمة `pyzk` على
PyPI تفشل أحياناً بالبناء (`setup.py`) على بعض إصدارات pip/setuptools
الحديثة رغم إنها مكتبة بايثون خالصة بدون أي كود C. نسخها هنا يضمن عملها
دائماً بدون الحاجة لأي أداة بناء أو تعديل بيئة.

لا حاجة لتشغيل `pip install pyzk` - الاستيراد `from zk import ZK` يعمل
مباشرة من هذا المجلد.
